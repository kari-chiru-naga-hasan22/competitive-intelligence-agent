## 5. Visual Styling Guidelines for Publishing

1. **Crisp High-DPI Captures:** Capture screenshots at 100% or 125% browser zoom for optimal text readability.
2. **Clean Cropping:** Crop browser window frames, bookmarks, and developer tabs so only the application UI is visible.
3. **Consistent Theme:** The application is styled in a clean light mode with slate borders and indigo/violet accents; ensure captured visuals match this palette.
